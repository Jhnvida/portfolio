# Portfólio — João André

Portfólio minimalista e editorial desenvolvido com Next.js (App Router), TypeScript, Tailwind CSS v4, GSAP e Lenis.

## Tecnologias

- **Framework:** Next.js 16 (App Router)
- **UI & Estilização:** React 19, Tailwind CSS v4, Lucide React
- **Animações & Scroll:** GSAP 3 (ScrollTrigger), Lenis Smooth Scroll
- **Tipagem:** TypeScript 5
- **Gerenciador de Pacotes:** pnpm

## Desenvolvimento

Instale as dependências e inicie o servidor local:

```bash
pnpm install
pnpm dev
```

Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.

## Scripts Disponíveis

- `pnpm dev`: Inicia o servidor de desenvolvimento.
- `pnpm build`: Cria a build otimizada de produção.
- `pnpm start`: Executa a aplicação construída em modo de produção.
- `pnpm lint`: Executa a verificação estática com ESLint.
